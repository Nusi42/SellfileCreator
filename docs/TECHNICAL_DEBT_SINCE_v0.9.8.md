## 4. New technical debt introduced since v0.9.8

## 4. Technical debt introduced since v0.9.8
- `src/components/TesterItemsGrid.tsx:302-420,1878-1910` now leans on `@tanstack/react-virtual`, but we still lack deterministic coverage for the overscan counts and height estimator. This inflates initial load and memory, especially in browsers without compression caching. We should either lazy-load per-ID (defer to `import.meta.glob` dynamic imports) or ship a CDN-backed sprite instead of bundling everything eagerly.
