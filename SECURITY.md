# Security

## Reporting a problem

If you find a security problem in Sellfile Creator, please report it privately, not in a
public issue:

1. Open the [Security tab](https://github.com/Nusi42/SellfileCreator/security) of this
   repository.
2. Choose **Report a vulnerability** and describe what you found.

Only the maintainer sees the report. Please include what is needed to understand and
repeat the problem: the Sellfile Creator version or the commit, the steps, what you
expected and what happened, and how serious you think it is. Never attach your real gear
database, account names or player ids; describe them or use made-up examples.

You will get an answer within a week. Once the problem is fixed, the fix ships in a release
with a short note, and you are named as the finder if you wish.

## What is covered

Fixes go into the newest release and the `main` branch; older releases are not patched.

Please test only on your own computer and your own game account, and do not read, change
or delete data that is not yours while you look for a problem.
